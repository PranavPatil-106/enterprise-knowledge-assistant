# IT Security and Data Protection Policy

## 1. Objective
This policy defines the security standards required to safeguard NovaCorp information assets, customer data, and computing infrastructure from unauthorized access, loss, or compromise.

## 2. Password and Authentication Standards
- **Password Complexity**: Passwords must contain a minimum of 14 characters, including uppercase, lowercase, numbers, and special symbols.
- **Rotation Period**: Passwords must be updated every 90 days. Reusing the last 5 passwords is prohibited.
- **Multi-Factor Authentication (MFA)**: MFA is mandatory for all internal services, email access, and cloud console logins via standard authenticator apps or hardware security keys.

## 3. Device and Endpoint Management
- **Screen Lock**: Workstations must be configured to automatically lock after 5 minutes of inactivity.
- **Full-Disk Encryption**: All corporate laptops must have BitLocker or FileVault enabled at all times.
- **Software Installations**: Employees may only install software approved and whitelisted in the NovaCorp Software Center. Personal software and peer-to-peer applications are strictly prohibited.

## 4. Data Classification and Handling
- **Public**: Information intended for general public release (press releases, public blogs).
- **Internal**: Standard operational documents intended for internal NovaCorp staff only.
- **Confidential / Restricted**: Financial records, customer PII, source code, and employee personal data. Must be encrypted at rest and in transit.

## 5. Incident Reporting
Any suspected security breach, lost device, or phishing attempt must be reported immediately (within 1 hour) to the Security Operations Center (SOC) at `soc@novacorp.local` or via hot line ext. 4444.
